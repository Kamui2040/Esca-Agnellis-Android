# Store screenshot provenance

This file records the exact v0.16 localized phone screenshots shipped with the upstream Fastlane metadata.

## Capture and privacy contract

- Captured from Esca Agnellis on Android 16 using deterministic synthetic/public-safe tracking state.
- `Today`, `Overview`, and `Statistics` were captured with the optional companion disabled/absent.
- `Companion` was captured from an isolated synthetic companion state with no personal name, authentic history, or authentic balance.
- Android status/navigation chrome was cropped; only the Esca app region remains.
- No authentic user tracking, backup, companion, device-identity, account, Drive, or private QA data is embedded in these files.
- Every image was visually reviewed at final size for localization fit, crop, system-chrome leakage, overlay contamination, and readability.

The screenshot compositions are project documentation/marketing media licensed under `CC-BY-4.0` to the extent K2040 can grant the relevant rights. Embedded Esca artwork retains the licence/provenance recorded in `ASSET_PROVENANCE.yml`. Platform-rendered UI primitives and fonts are not redistributed here as standalone source assets.
